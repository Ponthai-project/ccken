# 中間報告資料スライド6（研究の目的・検証仮説・分科会）の作成

## 1. 背景と経緯

2026年度 三菱CC研究会 第3研究部会の中間報告（9月下旬提出・10/2発表）に向け、副主査用フォーマット
`personal_doc/中間報告資料/01_2026年度第3研究部会_中間報告_副主査用フォーマット.pptx` の6スライド目
（「2. 研究の目的 ～検証する仮説～」）を作成する必要が生じた。

雛形は前年度（アジャイル部会）の内容で埋まっており、**形式は流用しつつ内容を全面差し替える**という前提である。
雛形は分科会3つ構成だが、今年度は合宿の討議で分科会が**4つ**に決定している（`分科会.md`）。
この 3→4 の差が本件最大の論点となった。

## 2. 決めるべきだったこと

1. 分科会が3→4に増えることをレイアウトでどう吸収するか
2. PPTXをどの方式で編集するか
3. 各分科会の「研究手法」欄に何を書くか（雛形には「アジャイル先進企業(8社)へのヒアリング」等の具体値が入っているが、今年度の該当データが参考資料に存在しない）
4. 成果物を原本上書きとするか別名保存とするか

## 3. 検討した選択肢

### 論点1：4分科会のレイアウト

| 案 | 内容 | 判定 |
|---|---|---|
| 案A 横4列・幅を単純4等分（幅5.57cm）・16pt維持 | 既存の左右端とカード間ギャップを保ったまま4分割 | **却下。** 収容量が 8字×6行＝約48字となり、現行3枚構成（約75字）から36%減。テーマ行だけで枠を食い研究手法が入らない。文言を削らねば成立せず、CLAUDE.md第10条A（形式が内容を侵すな）に抵触 |
| **案B 横4列・余白詰め＋本文14pt＋カード増高（採用）** | 左右余白を目的文帯の幅に合わせて広げ（x=150000〜8994000）、カード間ギャップを186073→120000に詰め、カード幅2121000（5.89cm）を確保。本文16pt→14pt、本文箱高を1758375→1900000に増やす | **採用。** 収容量が約80字となり現行3枚構成（約75字）を上回る。**内容を一切削らずに4枚化できる**唯一の案 |
| 案C 2×2の田の字・16pt維持 | カードを2行2列に配置 | 却下。カード高が半減して1枚4行しか入らず、かつ上部の目的文帯・検証仮説枠を圧縮せねば縦が足りない。上部を削ることになり第10条Aに抵触。案Bが溢れた場合の第二案として温存したが、実機検証で案Bが収まったため不要となった |
| 案D 3枚のまま＋4つ目を注記で補う | 雛形の構成を変えない | 却下。4分科会が並列であるという事実を歪める |

### 論点2：PPTX編集方式

| 案 | 判定 |
|---|---|
| python-pptx でAPI操作 | **却下。** python-pptx は grpSp（グループ図形）の新規追加APIを持たない。4枚目のカードを作れず、結局 `_element` への lxml 直挿入になり中途半端 |
| **XML直編集＋zipfile再パック（採用）** | **採用。** grpSp を丸ごと複製できるため書式属性が1文字も変わらず、「形式はそのまま」という要件を最も確実に満たす。記述量も少ない |
| グループを解体して単体図形8枚に | 却下。雛形の構造を変えると以後の保守で雛形との差分が読めなくなる |
| PowerPoint GUIでの手作業 | 却下。ただしXML直編集が3回失敗した場合の退避経路として温存した（発動せず） |

### 論点3：研究手法欄の書き方

| 案 | 判定 |
|---|---|
| 具体値を推定して記入 | **却下。** 参考資料に根拠がなく捏造にあたる |
| 具体値を一切書かず共通ステップのみ | 殿の判断で不採用。後から数値を入れる予定があるため |
| **プレースホルダー方式（採用）** | `（　社）``（　件）`（全角空白1つ）を置き、殿が後から具体値を差し込めるようにする |

### 論点4：目的文の長さ

`研究の進め方.md` の原文「アジャイルやウォーターフォールといった特定の手法論に依存せず」を含む本則版（約144字）は、
目的文帯（18pt・幅25.09cm・高2.58cm＝3行）に対し約3.5行分となり収まらないことが机上計算で判明。
短縮版（「特定の手法論に依存せず」＝約128字）を採用し、3行に収まることを実機レンダリングで確認した。

上下の余裕は合計約0.6cmしかなく、18ptの4行目（0.76cm）には届かない。よって本則版を復活させるには
文末（「再現性のある提言を導き出すことを目的とする」）の圧縮が別途必要であり、**この判断は殿の未決事項として残している**。

## 4. 決定と決め手

- **レイアウトは案B（横4列・本文14pt・カード増高）を採用。** 決め手は「収容量が現行3枚構成を上回るか」の一点。
  案Aは内容を削らねば成立せず、案Cは上部を削らねば成立しない。案Bだけが**何も削らずに4枚化できる**。
  CLAUDE.md第10条の「AとBのどちらか一方に倒して楽をすることを禁じ、両立の道を探す」に従った結果である。
- **編集方式はXML直編集。** 決め手は grpSp の複製可否。
- **カード見出しは14pt＋`lIns=0 rIns=0`。** 幅5.89cmで16ptだと9.5字しか入らず「【分科会2：開発モデル】」（11.5字相当）が2行に折り返す。
  14pt化と左右余白の除去で11.9字まで確保し、4枚とも1行に収めた。
- **研究手法欄は各分科会で差し分ける。** 初版では分科会1と3が同一文言となり報告資料として埋め草に見えたため、
  `研究の進め方.md` の「文献調査における4つの観点」を根拠に、価値定義／プロセス移行／品質保証／組織・人材の観点を明記した。
  カード本文に縦の余白が1〜2行分残っていたため、**何も削らずに追記できた**。
- **成果物は別名保存。** 雛形は原本として無傷で残す。

## 5. 実施結果

- 成果物：`personal_doc/中間報告資料/02_2026年度第3研究部会_中間報告_v1.pptx`
- 変更範囲：`ppt/slides/slide6.xml` のみ。他の9スライドを含む全エントリが雛形とバイト単位で一致することを確認済み
- think-cell の隠しオブジェクト（graphicFrame id=5、rId1/rId4/rId5参照）には一切触れていない

### 最終座標

| 要素 | off (EMU) | ext (EMU) |
|---|---|---|
| 下向き三角形 | y: 2406976 → **2360000** | 変更なし |
| カード見出し帯 ×4 | x=150000 / 2391000 / 4632000 / 6873000、y=**2700000** | **2121000 × 371513** |
| カード本文箱 ×4 | 同x、y=**3071513** | **2121000 × 1900000** |

グループの `off`/`chOff` は雛形では280261 EMUずれていたが、**`off==chOff`・`ext==chExt` に統一**して子図形に実描画座標を直書きする方式に改めた。以後の座標編集で同じ罠を踏まないためである。

### 検証

CLAUDE.md第9条に従い、静的解析に留めず**実機レンダリング（PowerPoint COM）で目視検分**した。

- 実機で確認：目的文帯3行・検証仮説2段落各1行・カード見出し4枚とも1行・カード本文4枚とも溢れなし
- 静的に確認：XMLのwell-formed性、`cNvPr id` の一意性、slide6以外のバイト一致

再利用可能な道具として以下を固定パスに新設した（CLAUDE.md第8条）。

- `~/.claude/bin/pptx_dump.py` — 指定スライドの図形ツリー（名前・座標・サイズ・テキスト）をダンプ
- `~/.claude/bin/pptx_render.ps1` — 指定スライドをPNGに書き出す（PowerPoint COM）
